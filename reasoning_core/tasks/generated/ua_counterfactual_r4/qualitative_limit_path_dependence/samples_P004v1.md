## Level 0

**Example 1**

Prompt:

```
Consider the multivariable rational function
    f(x, y) = (x + y) / (-x + y)
defined wherever its denominator is nonzero. As the point (x,y) approaches the origin along all admissible paths, does f(x,y) approach a single value that is the same for every admissible path? If yes, give that limit as a reduced rational number (use 0 for zero, 1/2-style for fractions). If different admissible paths give different limits, write DIVERGES. The answer is one value.
```
