## Level 0
### Example 1
Two independent capture rounds were run on a closed population of marked individuals, and each individual was equally likely to be captured in each independent round. List 1 contained the individuals {10, 18, 29, 34, 43, 46, 49}. List 2 contained the individuals {25, 29, 49}. Under these assumptions, use the Chapman estimator N = floor((n1+1)(n2+1)/(m+1)) - 1, where n1 is the size of List 1, n2 the size of List 2, and m the number of individuals appearing in both lists, to estimate the total population size. What is N? Answer with a single integer.

Answer: 9
