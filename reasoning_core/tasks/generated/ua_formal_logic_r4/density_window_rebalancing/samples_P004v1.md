## Level 0

### Prompt

An ordered array of 11 cells is gapped; a record occupies cells [0, 3, 5, 6, 7]. A window is any 4 consecutive cells. Every window must have density (occupied cells divided by 4) between 0.3 and 0.75. You may move a record from one cell to an empty cell, one record per move, never changing the total number of records. What is the minimum number of moves so that every 4-window satisfies the density bound? Layout: X..X.XXX.... The answer is a single non-negative integer.

### Answer

2
