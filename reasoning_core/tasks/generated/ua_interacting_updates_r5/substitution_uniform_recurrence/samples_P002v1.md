# Level 0

### Example 1

**Prompt:**

An infinite word is built by repeatedly applying the nonerasing Pisot substitution {a -> bac, b -> bac, c -> cb} starting from the prolongable seed letter 'b'. A factor recurs with bounded gaps if every two consecutive occurrences are separated by at most some fixed bound, and the word is uniformly recurrent when every finite block that occurs does so with bounded gaps. Is this word uniformly recurrent? Answer exactly 'yes' or 'no'.

**Answer:**

yes
