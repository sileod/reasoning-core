# Samples P005v1

## Level 0
### Prompt
Starting from an empty tableau, insert the symbols 1, 2, 5 one at a time in order using Schensted row insertion: in each row, the inserted value bumps the smallest entry strictly greater than it down to the next row (which then repeats the process); if no row entry is greater, the value is appended at the end of the row. Give the final row-sorted tableau as semicolon-separated rows, each row's entries comma-separated, top row first. For example, the tableau with rows [1,3] then [2] is written "1,3;2".
### Answer
1,2,5
