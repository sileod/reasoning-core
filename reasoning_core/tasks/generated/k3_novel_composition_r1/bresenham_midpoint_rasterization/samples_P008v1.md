## Level 0

**Prompt:**
```
Using Bresenham's midpoint line-drawing algorithm (the standard textbook variant), rasterize the integer segment from (7,10) to (10,7) on the integer lattice. Give the answer as the segment's ordered list of lattice points from start to end: each point as (x,y), consecutive points separated by a comma with no spaces, e.g. (1,1),(1,2),(1,3).
```
**Answer:**
```
(7,10),(8,9),(9,8),(10,7)
```
