## Level 0

### Example 1
**Prompt:**
Start from the partition lambda = 5 3 (rows of boxes, top row first). You will remove rim strips one at a time from its Young diagram. A rim strip is a connected set of boxes on the boundary of the current diagram that contains no 2x2 block, and removing it must leave a partition. You must remove strips whose box counts match the given sizes in order: sizes = 2 1. In each complete removal history you use up exactly all the given sizes in order, and a branch that cannot remove a strip of the current required size contributes nothing. Every time you remove a strip of height h (the number of distinct rows it spans) it contributes a factor (-1)^(h-1)/h. The signed total is the sum, over all complete removal histories, of the products of the per-strip factors. Report the signed total as a single reduced fraction a/b with b > 0, writing integers with denominator 1, e.g. 3/1, -5/2 or 1/2. Give only the reduced fraction as your answer.

**Answer:**
13/1
