# Level 0

In a process-dissociation task a participant must recognize a target word. The controlled recollection route and the automatic memory route operate in parallel and independently; the target is recognized if either route triggers. The automatic route triggers with probability 5/100 on each of 1 independent opportunities; the controlled route triggers with probability 3/100 once. Given that the target was recognized, compute the conditional probability that the automatic route was the one that produced it. Give your answer as a reduced fraction a/b.

Answer:
100/157
