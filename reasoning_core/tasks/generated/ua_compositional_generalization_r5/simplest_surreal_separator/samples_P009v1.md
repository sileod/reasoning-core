# Level 0
## Example 1
**Prompt:** A surreal number is a cut { L | R } with every number in L less than every number in R. It is born on the day equal to the smallest nonnegative integer n for which its value exists among numbers born on day n; every finite dyadic rational is born on a finite day. Consider the cut with left option -1/4 and right option 1. Find the earliest-born number strictly greater than every left option and strictly less than every right option. If no number lies strictly between them, making the cut not a proper cut, answer 'invalid'. Answer as a canonical surreal value like '3/4' or '-1/2', or the exact string 'invalid' when no such number exists.

**Answer:** 1/2
