```
Index : 0  1  2  3
Value : -2  -1  -4  -11

Because the polynomial has degree 2, its (3)-th forward difference is identically zero.
Use the forward-difference table to extend the sequence past index 3 and find the value of the polynomial at each queried index below.
Queried indices, already in increasing order: 6, 8

The answer is the polynomial value at each queried index, in the same increasing order, written as space-separated integers (for example "7 12" for two queried indices).
```

**Answer**
```

```
