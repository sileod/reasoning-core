# Dual number evaluation samples

## Level 0

### Example

Dual numbers extend the reals with an infinitesimal element e satisfying e*e = 0; a dual number a + b*e represents a value a with infinitesimal part b. Evaluating a differentiable function f at the dual input x0 + e yields f(x0) + f'(x0)*e.

Given the rational function R(x) = P(x)/Q(x) with rational coefficients below, evaluate R at the dual point x0 + e. Answer with the exact pair of reduced fractions 'value; derivative', i.e. f(x0); f'(x0). Write each rational as numerator/denominator with denominator positive, or as a plain integer when the denominator is 1 (zero is '0').

P:
-1/2

Q:
-x^2-1/2x-1/2

X0:
3

**Answer:**

1/22; -13/484
