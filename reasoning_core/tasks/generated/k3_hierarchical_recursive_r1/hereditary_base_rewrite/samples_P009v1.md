## Level 0

### Example 1

**Prompt:**

```
The hereditary base-2 form of 54 is 2^(2^(2)+1)+2^(2^(2))+2^(2)+2. Apply one Goodstein step: replace every occurrence of 2 (including inside exponents) by 3, evaluate, then subtract one. Write the result in hereditary base-3 form. Answer with the expression only, using non-negative integer digits, +, *, ^, and parentheses (no spaces, no equals).
```

**Answer:** `3^(3^(3)+1)+3^(3^(3))+3^(3)+2`
