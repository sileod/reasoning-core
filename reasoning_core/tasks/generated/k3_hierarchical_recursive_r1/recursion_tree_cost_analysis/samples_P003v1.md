# Samples for P003v1

## Level 0

### Example 1

**Prompt:**

Consider a divide-and-conquer recurrence on a problem of size 12. Every node of size n spawns 2 child nodes, each of size n//2. A node of size 0 or 1 is a leaf and spawns no children. Every node of size n contributes work equal to 8*n + 2. Build the full recursion tree and compute the total work summed over all nodes in the tree. What is the exact total? Answer with one integer.

**Answer:** 382
