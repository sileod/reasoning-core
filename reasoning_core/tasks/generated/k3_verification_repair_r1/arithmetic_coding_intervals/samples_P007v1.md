## Level 0

**Prompt:**

Arithmetic coding uses the fixed symbol order a, b, c with cumulative probabilities a=1/2, b=1/3, c=1/6 over the interval [0,1). Each symbol narrows the current interval to its own share. Code the word "cbab" by applying each symbol in turn. Report the final interval as the low and high numerators over the common denominator 1296, two fractions separated by a space, as in "3/36 9/36".


**Answer:**

1206/1296 1218/1296
