# Level 0

### Example 1

**Prompt:**

Consider the unweighted undirected graph with vertices 0..5 and edges { 0-1, 0-2, 0-3, 0-4, 1-2, 1-4, 2-3, 2-5, 4-5 }. Compute the exact betweenness centrality of vertex 3, defined as the sum over all ordered pairs of vertices (s,t) with s,t distinct from 3, of the number of shortest s-t paths that pass through 3 divided by the total number of shortest s-t paths. Give the answer as a single reduced fraction p/q.

**Answer:** 0/1
