# Level 0
### Example 1
**Prompt:**
A wrench acting on a rigid body is described at the reference point P=[2, 0, -1] by a resultant force vector F=[-1, 5, 1] and a moment vector M=[-11, 0, -11] about P (standard right-handed basis). Reexpress it as its central axis: give a point that lies on the central axis together with the axis direction, and the screw pitch. Answer format: '[x, y, z] along [dx, dy, dz] | pitch', where the point coordinates are reduced fractions, the direction integers are reduced with the first nonzero component (x then y then z) positive, and the pitch is a reduced fraction. If F is the zero vector and M is not, it is a pure couple and you must answer exactly 'pure couple | pure couple'.
**Answer:**
[-11/5, 0, 11/5] along [1, -5, -1] | 0
