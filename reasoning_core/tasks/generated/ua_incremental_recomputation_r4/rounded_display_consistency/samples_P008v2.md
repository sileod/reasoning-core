## Level 0

Prompt 1:

A merchant records three linked readings, all rounded to a nearest step with half-up ties and a shared grid offset of 0:
quantity A reads -16 (step 1).
quantity B reads 8 (step 1).
the sum A + B reads -8 (step 1).
All three readings come from one consistent pair of whole-count quantities A and B. What is the tightest possible whole-number range for quantity A over every consistent assignment? Reply with the tight range such as [3, 7]; if no assignment is consistent, reply with the single word no instead.

Answer: [-16, -16]
