# Level 0
## Example
We have a realizable oriented matroid whose ground set is E = {0,...,3}, realized as the columns of an integer matrix of rank 2 (each element is a vector in R^2). This is the complete covector data.
  element 0: [3, 1]
  element 1: [-3, 0]
  element 2: [0, -2]
  element 3: [2, -1]
A signed circuit is a minimal-support integer linear relation among a set of columns that sums to zero. We use its canonical form: reduce to coprime coefficients and multiply by +/-1 so the smallest-index nonzero coefficient is positive; a loop (zero vector element) always gets value 0. The signed circuit on a minimal dependent support is unique in this canonical form.
The queried coordinates, in order, are [0, 2, 3]. State the canonical signed circuit value at each queried coordinate, one integer per coordinate in that same order, separated by commas (e.g. the format '3,-1,0' means the three queried coordinates carry 3, -1 and 0).
Answer:
4,5,-6
