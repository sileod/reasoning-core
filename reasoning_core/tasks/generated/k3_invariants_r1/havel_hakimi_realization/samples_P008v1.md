## Level 0

### Prompt

Apply the Havel-Hakimi reduction to the degree sequence [6, 5, 4, 4, 3, 3, 3], listed largest to smallest. Each round: take the largest remaining degree d; if d is greater than the number of remaining vertices minus one, the sequence is not graphical and that round fails; otherwise subtract 1 from the d next-largest remaining degrees and re-sort largest to smallest. Run exactly k=5 rounds, then give the outcome: if every degree reaches zero within those k rounds, answer exactly GRAPHICAL; if a round fails within those k, answer NOTGRAPHICAL followed by the sorted residual degrees at the failing round and the 0-based index of the unsatisfiable largest-degree vertex, as NOTGRAPHICAL residual index 0; otherwise answer RESIDUAL followed by the sorted residual degrees after the k rounds. Example answer formats: GRAPHICAL ; NOTGRAPHICAL 4,3,1 index 0 ; RESIDUAL 3,2.


### Answer

GRAPHICAL
