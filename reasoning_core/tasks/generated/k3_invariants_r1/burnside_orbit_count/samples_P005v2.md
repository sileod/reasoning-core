## Level 0

### Prompt

The symmetry group of a necklace of 2 beads has 2 elements. Each element is a permutation of the positions, written in cycle notation over the positions numbered 1 to 2 (a one-cycle like (3) is a fixed point).
Group elements:
(1)(2)
(1 2)
Color each position with one of 2 available colors.
Using Burnside's lemma, count the distinct colorings up to symmetry (the number of orbits), averaging the number of arrangements each group element leaves unchanged over all 2 group elements.
Give the answer as a single simplified fraction p/q in lowest terms (write an integer n as n/1).

**Answer**: 3/1
