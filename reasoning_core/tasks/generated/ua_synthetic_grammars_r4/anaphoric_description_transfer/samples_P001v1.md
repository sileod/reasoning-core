## Level 0
### Prompt
Here are facts about a cast of people:
the supervisor of Ada is Noah
the supervisor of Chris is Vera
Reading a description like "the supervisor of (the <binder>)" means: resolve the chain deepest-first from the binder.
With Ada as the binder, that description denotes Noah.
Now the outer possessor is switched: Chris becomes the binder instead of Ada.
Under the new binder Chris, whom does the description denote? Answer with exactly one name.

### Answer
Vera
