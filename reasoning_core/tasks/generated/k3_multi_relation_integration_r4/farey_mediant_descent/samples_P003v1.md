## Level 0

### Example 1

**Prompt:**

Consider the reduced fraction 5/6. Run the Stern-Brocot mediant descent starting with the Farey neighbors 0/1 and 1/0: at each step take the mediant of the two neighbors, write L when 5/6 lies strictly below that mediant and R when it lies strictly above it, then move into the corresponding half (when it equals the mediant, the descent has reached 5/6 exactly and stops). Give the L/R path to 5/6: a string of L and R only, nothing else.

**Answer:**

LRRRR
