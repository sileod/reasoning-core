## Level 0

### Example 1

Build the palindromic tree of the string 'abbbabbabbab' symbol by symbol using longest-suffix links. How many times does the palindrome 'bb' occur as a substring of 'abbbabbabbab'? Answer with a single non-negative integer.

Answer: 4

### Example 2

Build the palindromic tree of the string 'ababaaabaa' symbol by symbol using longest-suffix links. How many times does the palindrome 'aba' occur as a substring of 'ababaaabaa'? Answer with a single non-negative integer.

Answer: 3
