## Level 0

### Prompt

You run a refinery with several recipes. A recipe lists which resources it consumes and which it produces. All resources are fully conserved: whatever you produce stays available for later use (including recycling), and whatever you consume is gone. The only resource you can buy to start is the limiting resource; it is never produced by any recipe.

Recipes:
  recipe 0: consume 2 R0 -> produce 5 R3
  recipe 1: consume 2 R1, 3 R3 -> produce 2 R1, 2 R3

You must end with at least 6 units of R3 on hand. You may run any recipe any number of times, in any order, spending produced resources freely.

What is the minimal initial stock of the limiting resource R0 that lets you end with the required amount? Answer with one integer.

### Answer

4
