# samples_P008v2

## Level 0

### Example 1

**Prompt:**

```

Consider the plane curve f(x, y) = 0 with f(x, y) = ((y^1 - x^1))((y^3 - x^4))((y^1 - x^2)). Its Puiseux branches near the origin are fractional-power series y = c*x**e + ... where each factor y^q - x^p contributes q complex branches with leading exponent e = p/q. Order all 5 branches by increasing leading exponent e. The ramification index of a branch is the least common denominator of its fractional exponents in lowest terms. What is the ramification index of the 5-th branch (1-indexed)? Answer with the integer.

```

**Answer:**

```

1

```
