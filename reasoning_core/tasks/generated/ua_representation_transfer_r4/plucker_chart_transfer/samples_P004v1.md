Change chart: transfer from the pivot set P = (0,2) to the pivot set Q = (1,2). Give the ratio of the new (Q) Plucker coordinate to the old (P) Plucker coordinate, computed from scratch in the new chart. Answer as a single reduced fraction, e.g. -2/3 or 5.

Answer: 8/5
