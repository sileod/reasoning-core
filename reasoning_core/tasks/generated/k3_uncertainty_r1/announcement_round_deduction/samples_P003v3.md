## Level 0
### Example
Agents A0..A6 each wear a hat that is either Red or Blue; each agent sees everyone else's hat but not their own. It is publicly announced that at least one agent wears a Red hat. In each round, every agent who still cannot name their own hat color says 'I don't know' all at once, and then worlds inconsistent with that announcement are dismissed. The hats: A0 cannot see their own hat; A1 wears a Red hat; A2 wears a Blue hat; A3 wears a Red hat; A4 wears a Blue hat; A5 wears a Blue hat; A6 wears a Blue hat; After how many rounds does the first agent deduce their own hat color, and which agent (lowest index among those who deduce in that round) is it? Answer as "A<index> on round <number>", e.g. "A0 on round 1".

Answer: A0 on round 3
