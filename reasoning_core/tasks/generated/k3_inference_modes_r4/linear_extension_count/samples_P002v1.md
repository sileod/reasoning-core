## Level 0
Prompt:
Consider the partial order on the vertex set {0,...,4} whose cover relations (each "x < y" means x is covered by y, i.e. x is below y with no element between) are: 0 < 1; 1 < 2; 1 < 3; 1 < 4. A linear extension is a total ordering of all vertices that respects every cover relation. Count the number of linear extensions of this partial order by a down-set dynamic program (or, for trees, the hook-length product formula). The answer is one non-negative integer: the exact number of linear extensions.
Answer:
6
