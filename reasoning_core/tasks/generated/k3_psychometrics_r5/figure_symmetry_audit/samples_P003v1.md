## Level 0
### Prompt
The figure below is a 5x5 grid where 'X' marks filled cells and '.' empty cells.
.X.X.
X...X
..X..
X...X
.X.X.
List the reflection axes (H=horizontal, V=vertical, D1=diagonal top-left to bottom-right, D2=diagonal top-right to bottom-left) that map the filled cells exactly onto themselves, and the rotation order (2 for 180 degrees, 4 for 90 degrees, or 1 if there is no rotational symmetry). Give axes first then rotation, as A:V,H;R:4. If no axes apply, write A:None.

### Answer
A:H,V,D1,D2;R:4
