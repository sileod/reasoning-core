## Level 0

### Example 1

Prompt:

Numeral system: each symbol has the value: A=37, B=29, C=401. Reading left to right, if a symbol's value is smaller than the following symbol's value, subtract it from the next symbol; otherwise add it. What integer does the string 'AA' equal? Answer one integer.

Answer: 74

### Example 2

Prompt:
