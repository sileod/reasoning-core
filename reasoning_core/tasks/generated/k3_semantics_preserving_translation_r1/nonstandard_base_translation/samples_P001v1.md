# Level 0

Write the integer 31 in balanced ternary, whose digits are in {-1, 0, 1}. Give exactly the digit string in that system, most significant digit first, with each digit separated by a space and -1 written as -1. For example the integer 5 is written 1 -1 -1 in balanced ternary (5 = 9 - 3 - 1).

Answer: 1 0 1 1
