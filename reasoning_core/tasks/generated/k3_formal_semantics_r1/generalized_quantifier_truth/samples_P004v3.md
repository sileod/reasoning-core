# Samples: generalized quantifier truth (P004v3)

## Level 0

**Prompt:**

Indicate whether the statement below is true or false; reply with exactly True or False. Consider a model with universe U = [1, 2, 3, 4], set A = [3, 4], and set B = [1, 2, 3, 4]. Statement: Exactly 0 elements of A are in B.

**Answer:**

False


**Prompt:**

Indicate whether the statement below is true or false; reply with exactly True or False. Consider a model with universe U = [1, 2, 3, 4], set A = [2, 3, 4], and set B = [1, 2, 3]. Statement: Most elements of A are in B.

**Answer:**

True
