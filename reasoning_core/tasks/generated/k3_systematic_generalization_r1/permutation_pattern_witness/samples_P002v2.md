## Level 0

### Example

Prompt:

Given a text permutation T and a pattern permutation P, T contains P if there is a strictly increasing sequence of indices i1<i2<...<ik with T[i1],T[i2],...,T[ik] = P as a sequence of values. Decide whether T contains P, where T = [6 1 2 3 5 4] and P = [6 2 5]. Report the lexicographically smallest 1-based index tuple that realizes it, or the single word NONE when no such indices exist

Answer:

1 3 5
