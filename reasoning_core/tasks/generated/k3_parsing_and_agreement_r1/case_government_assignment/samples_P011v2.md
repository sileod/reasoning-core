## Level 0

### Example 1

**Prompt:**

In this constructed language, assign grammatical case to each noun phrase.

Clause:  the hunter strikes

Grammar notes (the rules that fix the cases):
  • An intransitive verb assigns nominative to its sole argument (the subject).

Arguments, each taking exactly one case:
  1. "the hunter" — the subject

Candidate assignments, each listing one case per argument in the order above:
  A. NOM
  B. ACC

Which candidate (A–B) assigns the correct case to every argument? Answer with the single letter.

**Answer:** A

## Level 5

### Example 1

**Prompt:**

In this constructed language, assign grammatical case to each noun phrase.

Clause:  the weaver lends the ticket to the miller beside the harbor

Grammar notes (the rules that fix the cases):
  • The subject of a finite verb bears nominative case.
  • A direct object bears accusative case.
  • An indirect object bears dative case.
  • The preposition "beside" governs dative on its object.

Arguments, each taking exactly one case:
  1. "the weaver" — the subject
  2. "the ticket" — the direct object
  3. "the miller" — the indirect object
  4. "the harbor" — the object of "beside"

Candidate assignments, each listing one case per argument in the order above:
  A. NOM, ACC, ACC, DAT
  B. NOM, ABS, DAT, DAT
  C. ACC, ACC, DAT, DAT
  D. NOM, ACC, DAT, ACC
  E. NOM, ACC, DAT, DAT

Which candidate (A–E) assigns the correct case to every argument? Answer with the single letter.

**Answer:** E
