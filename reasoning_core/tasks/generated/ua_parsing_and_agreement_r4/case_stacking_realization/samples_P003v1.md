# Level 0

**Prompt:**
```
Consider a possessive chain where each nominal possesses the next one (N1 possesses N2). Form a chain of N objects, each with a nominal class; the chain classes are: N1:C, N2:B.

We ask about the suffix string realized on N2, which has class B and own clause case ACC, and whose stem ends in the consonant 'k'.

Case exponents by class:
Class A: NOM=na, GEN=an, ERG=sa, ACC=ma, DAT=ia
Class B: NOM=ru, GEN=er, ERG=tu, ACC=vu, DAT=eu
Class C: NOM=ci, GEN=og, ERG=ki, ACC=pi, DAT=au

Inheritance: a nominal realizes, in left-to-right order, its own case exponent followed by the GEN exponent of every possessor to its left in the chain.
Boundary & suffix-fusion: between adjacent units (the stem, then each stacked exponent), if the earlier unit ends in a vowel and the next exponent begins with a vowel, the next exponent's leading vowel is dropped; if the earlier unit ends in a consonant and the next exponent begins with a vowel, a linking 'j' is inserted; otherwise the next exponent attaches unchanged.

What suffix string is realized on N2? The answer is the concatenated suffix exponents only (for example 'maer' for a hypothetical ACC followed by two stacked GENs), not the stem.
```

**Answer:**
```
vug
```
