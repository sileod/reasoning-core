# Level 0

## Example 1

In complement coercion, an event-selecting verb applied to a noun whose denotation is an entity coerces that entity into one of its characterized events through stated purpose, creation, or use relations. Each relation names an event verb and a real-valued strength; the licensed interpretations are ordered from strongest to weakest relation, with ties broken by verb name. Coercion verbs: begin, finish, start, stop, enjoy. Event lexicon (entity: verb with strength):
article: read 2, write 1.5
book: read 2, write 1
door: paint 2
essay: write 3, read 1.5
film: watch 2.5, direct 1
garden: tend 2.5, clean 1
house: build 2, clean 1.5
meal: cook 2.5, eat 2
piano: play 2.5
play: perform 3, watch 1
poem: write 2.5, recite 1
puzzle: solve 2.5, assemble 2
report: write 3, read 1.5, review 1
room: paint 2, clean 1.5, decorate 1
sculpture: sculpt 3, view 1
song: sing 3, record 1, compose 1.5
symphony: compose 3, conduct 1
toy: play_with 2.5, make 1

For the verb 'start the poem', the selecting verb start coerces the entity poem into each event start(verb(poem)) for every relation of poem.

Instance: 'start the poem'
List the licensed event interpretations of this instance. Give only the bracket-enclosed list ordered by relation strength, e.g. ["begin(read(book))", "begin(write(book))"].

**Answer:** ["start(write(poem))", "start(recite(poem))"]
