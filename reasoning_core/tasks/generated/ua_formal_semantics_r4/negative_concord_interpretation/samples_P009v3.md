## Level 0

### Example 1

**Prompt:**

```
Under these dialect rules: Within a clause, several negatives realize a single negation (negative concord).
A complementizer boundary is transparent: all negatives from every clause pool together into one global count.
A negative indefinite in an embedded clause is licensed only when that clause also contains an overt negator or the matrix is negated; otherwise the reading is unlicensed.

Sentence: "none of the members acknowledge also no one that it didn't review"

State the overall truth conditions of the sentence as exactly one of: 'negated', 'asserted', or 'unlicensed'.
```

**Answer:**

`negated`

### Example 2

**Prompt:**

```

Sentence: "none of the members review also nothing"

State the overall truth conditions of the sentence as exactly one of: 'negated', 'asserted', or 'unlicensed'.
```

**Answer:**

`asserted`
