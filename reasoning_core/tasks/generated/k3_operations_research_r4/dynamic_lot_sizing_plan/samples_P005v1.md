## Level 0

**Prompt:**
Over a horizon of 5 periods, demand per period is [1, 1, 1, 0, 1]. Starting a production run in any period costs a fixed setup cost of 14; once a run is started, its produced units cover that period and every later period until the next run. A unit of stock held from one period into the next costs 5; demand in a period with no production must be met from earlier stock and cannot be backlogged. Find the set of production periods (space-separated integers, 0-indexed) achieving the minimal total cost; if several plans tie, give the lexicographically smallest one, e.g. '0 3'.

**Answer:**
0 2
