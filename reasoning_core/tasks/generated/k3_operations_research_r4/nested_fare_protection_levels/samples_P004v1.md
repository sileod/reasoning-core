# Level 0

A premium economy-cabin aircraft fares nested fare classes on one leg of total capacity 15. Fares are ordered high to low as listed, the top class highest. Daily demand for each class is independent and Poisson-distributed with the given mean:
  J: fare 795, demand Poisson(mean 3)
  C: fare 684, demand Poisson(mean 8)
Using single-leg expected-marginal-seat-revenue nesting, the airline sets each class's cumulative booking limit (the number of seats made available to that class) at the median fractile of the pooled demand of all classes at least as expensive as it: the smallest q with P(Poisson(pooled mean) > q) <= 0.5.
What is the availability count -- the nested booking limit -- for class C? Answer a single non-negative integer.

Answer: 11
