# Level 0
## Prompt
```
A loop on a cell complex has edge sequence 'dcC'. The complex has face 1: boundary bdac; face 2: boundary cdab; face 3: boundary bcad; face 4: boundary cbda. Allowed deformations: (1) spur insertion/removal -- delete an adjacent inverse pair x x' ; (2) face-boundary substitution -- replace a contiguous path of the loop that is an arc of a face boundary by the complementary arc of that face. Reduce the loop to length at most 2 while preserving the start vertex only. Give the sequence of loop words, separated by '>', listing the loop after each deletion from the start word down to a word of length at most 2, or 'impossible' if no such reduction exists.
```
## Answer
```
dcC>d
```
