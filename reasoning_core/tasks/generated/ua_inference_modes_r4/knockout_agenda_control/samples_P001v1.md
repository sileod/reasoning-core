## Level 0

Prompt:

We run a single-elimination knockout among seeds 1..4. For every pair, the listed outcome says which seed wins if they meet.

Seed 1 beats nobody.
Seed 2 beats: 1, 4.
Seed 3 beats: 1, 2.
Seed 4 beats: 1, 3.

There are no protected pairings.

Seed 1 is the designated champion that must be forced to win. Construct a valid full bracket in which seed 1 wins, respecting the protected pairings. If no bracket can make seed 1 win, answer exactly: Impossible

Otherwise answer with the bracket as round pairings of actual seeds, e.g. 'R1:1v8,4v5;R2:1v4;F:1v4' (fewest rounds first, final marked F); any valid bracket that forces seed 1 wins is accepted.

Impossible
