Example 1

Prompt:
A set of mutually recursive equivalence classes of expressions denotes integer values. To represent a value you start from the atom values [0, 1] (always available, free) and repeatedly combine two already-known values with an operator, keeping every intermediate result so any value may be reused by later steps at no extra cost (shared subterms count once). Each operator has a cost per use and a budget on how many times it may be used in total: add (cost 3, at most 3 uses); sub (cost 2, at most 1 uses); mul (cost 3, at most 1 uses). All values, including every intermediate, must stay between 0 and 13 inclusive. Your goal is to represent the value 4. What is the minimum total cost (summing each distinct operator use once) of a valid representation? The answer is one integer.

Answer:
6
