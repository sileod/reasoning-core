# P008v1 samples


## Level 0

### Example 1

**Prompt:**
Four labeled points P0, P1, P2, P3 on the real projective line have cross-ratio (P0,P1;P2,P3)=((P0-P2)(P1-P3))/((P1-P2)(P0-P3)), which is invariant under all fractional-linear (projective) coordinate changes between points on the line.
Their coordinates are:
  P0=2
  P1=?
  P2=-3
  P3=4
Their cross-ratio (P0,P1;P2,P3) equals 5/12.
Give the missing coordinate as a reduced fraction (e.g. 3 or 5/2).

**Answer:** 3
