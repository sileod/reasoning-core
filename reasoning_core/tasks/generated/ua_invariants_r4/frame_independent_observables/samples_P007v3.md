## Level 0

### Example 1

**Prompt:**

Consider the observable O = -2*x + -3*y + -1*t evaluated at t=1, x=1, y=-5, where x and y are spatial coordinates and t is time. Under a Galilean boost of the frame in which we give both spatial coordinates a shared constant velocity, can the value of O change? Answer yes if O is unchanged for every possible Galilean boost parameter, no if some parameter changes it. Answer with a single word.

**Answer:** no
