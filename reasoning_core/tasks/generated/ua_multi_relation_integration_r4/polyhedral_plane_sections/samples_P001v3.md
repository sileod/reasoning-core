## Level 0
### Example 1
A plane cuts a beveled polyhedron. The plane is an oblique plane and is given by (0.203) x + (0.738) y + (0.643) z = 1.077. The section of the solid by this plane is a convex polygon. How many vertices does the section have? The answer is a single integer.

Answer: 6

### Example 2
A plane cuts a right prism. The plane is a plane passing through an edge of the solid and is given by (-0.937) x + (0.349) y + (0.000) z = -0.624. The section of the solid by this plane is a convex polygon. How many vertices does the section have? The answer is a single integer.

Answer: 4
