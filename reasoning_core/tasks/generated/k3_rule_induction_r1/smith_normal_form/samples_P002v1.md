# Smith Normal Form samples (P002v1)

## Level 0

### Example 1

**Prompt:**

Compute the Smith normal form of the following 2x2 integer matrix using exact integer row and column operations, and give its nonzero invariant factors.

Matrix:
[[6, 2], [-6, 0]]

Answer as the sorted tuple of the positive diagonal entries d1 | d2 | ... | dk, for example (1, 2, 4). If the matrix reduces to all zeros, answer ().

**Answer:**

(2, 6)
