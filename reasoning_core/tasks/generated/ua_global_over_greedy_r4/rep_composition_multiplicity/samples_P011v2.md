# Level 0
## Example 1
Prompt:
The symmetric group S3 has three irreducible representations with character vectors on (identity, transposition, 3-cycle):
  T = (1, 1, 1)
  S = (1, -1, 1)
  E = (2, 0, -1)
Class sizes: 1 identity, 3 transpositions, 2 three-cycles.
The n-th symmetric power Sym^n and exterior power Ext^n are taken per conjugacy class from the relevant character value.
Compute the multiplicity of T in the direct sum Ext^2(T) + Ext^4(T). The answer is one non-negative integer.
Answer:
0
