# Level 0
## Example 1
2 rigid rectangular blocks are stacked on a rough horizontal floor. Every block has half-width a = 1.
From bottom (block 1) to top, block k has weight W_k = [2, 3] and height h_k = [3, 2].
The floor has static friction coefficient mu_0 = 2/3; the interface between block k and block k+1 has friction coefficient mu_k = ['1/4'].
A horizontal load P is applied to the center of the top block. Contacts are unilateral and friction follows a rational Coulomb cone. Find the largest load P for which the stack is in static equilibrium: no group of blocks slips on the surface below it and no upper group of blocks tips about an edge. Give P as one rational number (integer or fraction).

Answer: 3/4
