# Level 0

## Prompt

A parametric real polynomial has coefficients that depend linearly on the scalar t:
p_t(s) = c_2(t)*s^2 + c_1(t)*s^1 + c_0(t)*s^0, where the coefficients are:
c_0(t) = 1*t + 2, c_1(t) = -1*t + -1, c_2(t) = 1.
Using the Routh-Hurwitz criterion, find the set of all real t for which every root of p_t(s) lies in the open left half-plane (strictly negative real part).
Answer the complete region as a sorted union of disjoint real intervals with exact endpoints, e.g. '(-1/2, 2] U [3, inf)' or '[-2, 1]'; write 'empty' if no such t exists. Give the smaller endpoint first in each interval and order intervals left to right.

## Answer

(-2,-1)
