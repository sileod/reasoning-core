# Samples

## Level 0

### prompt
A finite group G is given by generators x1..x2 together with relations R1..R3, and a projective phase assigns each generator a phase.  Rephasing means adding an integer tau_i to each generator's phase.  The j-th relation publishes its signed multiplicities (the coefficient vector a_j = (a_j1..a_j2)) and its phase defect d_j; rephasing changes that defect to d_j + sum_i a_ji * tau_i.  The phase is consistently rephased modulo m when integers tau_1..tau_2 exist making every defect congruent to 0 modulo m.

R1: coefficients [12, -11], phase defect -2
R2: coefficients [0, 0], phase defect -3
R3: coefficients [-11, 0], phase defect 1

Find the smallest integer m >= 2 for which the phase can be consistently rephased.  If no such modulus exists, write `never`.  Answer with just that integer or `never`.

### Answer
3
