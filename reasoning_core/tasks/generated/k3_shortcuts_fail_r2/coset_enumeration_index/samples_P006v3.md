# Samples for P006v3 (coset_enumeration_index)

## Level 0

### Example 1

**Prompt:**

```
In a finitely presented group G generated by a and b, impose exactly the relations a^7, b^2, a*b*a*b, each equal to the identity e. Products are read left to right; negative exponents mean inverses. No other relations are imposed.
Let H be the subgroup generated by the words b*a*b*a (not their normal closure).
Use Todd–Coxeter coset enumeration: begin with H, define missing generator entries, close relator rows at every coset and subgroup rows at H, and merge coincidences including all consequences in the generator table. What is the index [G:H], the number of distinct right cosets Hg?
Return only a positive integer, for example 7.
```

**Answer:**

```
14
```
