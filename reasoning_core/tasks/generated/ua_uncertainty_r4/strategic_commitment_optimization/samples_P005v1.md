The follower, seeing the chosen action, then picks the follower action from {F0, F1} that maximizes the follower's own payoff (ties broken toward the smallest index, F0 before F1 before F2, and so on). The leader's payoff is the value in the selected cell of the payoff matrix below; the leader commits to the action that maximizes the leader's own payoff, and ties among leader actions are broken toward the smallest index.

Payoff matrix (rows are leader actions, columns are follower actions; each cell shows leader/follower payoff):
             F0     F1
L0         4/-6   6/-3
L1         2/-4   0/-5
L2          1/3    2/3

Which leader action does the leader commit to? Name exactly one action string from {L0, L1, L2}.
