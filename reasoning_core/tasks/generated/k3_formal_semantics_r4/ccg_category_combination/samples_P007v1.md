## Example 1

In Combinatory Categorial Grammar each word carries a slash category and adjacent categories combine by functional application or composition into a single category. Lexicon: a,the,an,no,every -> (NP/N); red,quick,big,small,lazy -> (N/N); fish,cat,snake,fox,dog,bird,mouse,whale -> N; police,kid,hen,tiger,crow -> NP; sings,dances,swims,runs,jumps,sleeps -> (S\NP). Fully combine the categories of the sequence 'a mouse' into one atom. Give only the final category, e.g. 'S' or 'NP'.

**Answer:** NP
