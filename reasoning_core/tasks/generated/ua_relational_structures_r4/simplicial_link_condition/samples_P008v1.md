## Level 0

Prompt:

A simplicial complex is given by its maximal faces (facets), each written as a dash-joined list of vertex numbers; the full complex contains every non-empty subface of these facets.
Facets: 0-1-4;0-2-4;1-3-5;1-4-5;2-3-4;2-3-5;3-4-5.
For a face sigma, its link Lk(sigma) is the set of all faces tau disjoint from sigma such that sigma-union-tau is also a face.  For an edge e={u,v}, say e satisfies the link condition when Lk(e) equals the intersection Lk(u) intersect Lk(v).
List every edge {u,v} of the complex that satisfies the link condition, as a comma-separated list of edges written 'u-v' with the smaller vertex first, in increasing lexicographic order of (u,v).  If no edge satisfies, answer exactly: none

Answer:

2-3,0-2,0-4,3-5,0-1,1-5
