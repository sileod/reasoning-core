## Level 0

Two matroids (or a chain of them) are joined by a series two-sum: the marked element of one is identified with the marked element of the next, and a set B is a basis of the composition exactly when B = (B1 - {p1}) | (B2 - {p2}) for bases B1, B2 of the joined pair with exactly one of them containing its own marked element. Apply that repeatedly in the given order to form the composed matroid.

Component 1: ground ['a', 'b', 'c', 'd'], marked element c, basis set {{a,b,c}; {a,b,d}; {a,c,d}; {b,c,d}}.
Component 2: ground ['e', 'f', 'g'], marked element e, basis set {{e,f}; {e,g}; {f,g}}.
A subset is independent in a matroid when it is contained in some basis. Is the set {a,g} contained in some basis of the composed two-sum matroid? Reply with exactly one of the two words.


Answer: yes
