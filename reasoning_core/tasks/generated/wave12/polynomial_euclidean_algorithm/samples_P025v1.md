# Level 0

## Prompt

Work in the finite field GF(7) (all arithmetic is modulo 7).
Each polynomial below is written as a coefficient vector listing coefficients from the highest-degree term down to the constant term; for example, [3, 0, 2] over GF(7) represents 3x^2 + 2.

P = [2, 6]
Q = [5, 3]

Using the Euclidean algorithm, compute the monic greatest common divisor gcd(P, Q) over GF(7) and report it as a coefficient vector (highest-degree first) of fixed length equal to max(deg P, deg Q) + 1, zero-padded to the maximum degree. Give the answer as that integer list, e.g. "0,0,1".

## Answer

0,1
