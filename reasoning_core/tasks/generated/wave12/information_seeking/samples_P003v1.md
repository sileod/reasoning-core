# Level 0
## Example 1
### Prompt
A model has a set of hypotheses, each of which may be true. You may ask exactly one yes/no question (an observation). For each candidate question below, the numbers in brackets are the indices of the hypotheses that would answer 'yes' to it.
Current hypotheses: H4, H2, H7.
All hypotheses are currently viable (indices [0, 1, 2]).
Candidate questions:
Q1: yes for [1, 2]
Q2: yes for none
Q3: yes for [1]
Choose the candidate question that best distinguishes the remaining hypotheses (split them as evenly as possible into yes and no groups). If two candidates split equally well, pick the lexicographically smallest name (Q1 < Q2 < ...). Answer with one candidate name only, e.g. Q2.

### Answer
Q1
