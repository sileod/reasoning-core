## Level 0

A discrete-time branching process starts in state A. At each step the current state moves to exactly one of its outcomes, drawn with the listed conditional probability, and the state changes to the outcome's destination. The transitions are independent across steps. The states and their conditional transitions are:
- From state A: to C with probability 1/2 (outcome loss), to C with probability 1/2 (outcome tails).
- From state B: to A with probability 1/2 (outcome down), to B with probability 1/2 (outcome hot).
- From state C: to B with probability 3/5 (outcome west), to B with probability 2/5 (outcome east).
What is the exact probability, as a reduced fraction p/q, that the process is in state C after 2 steps? Give only the fraction.

Answer: 0
