## Level 0
**Prompt:**
A cohort is cross-classified by binary instrument Z (0/1), binary exposure X (0/1), and binary outcome Y (0/1). The observed counts are:
Z=0, X=0: Y=0 has 31, Y=1 has 40
Z=0, X=1: Y=0 has 37, Y=1 has 33
Z=1, X=0: Y=0 has 37, Y=1 has 42
Z=1, X=1: Y=0 has 31, Y=1 has 34
Under an unidentified causal relation between a binary exposure X and a binary outcome Y, with no further assumption, giving the sharp Manski (natural) bound, compute the identified set for the average causal effect of X on Y, the probability difference E[Y(1)]-E[Y(0)]. Report the lower and upper endpoints of that interval, each rounded to 2 decimals, as `L,U` (e.g. `0.25,0.75`).

**Answer:** -0.53,0.47
