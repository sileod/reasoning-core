## Level 0

Each listed line is one experiment in a 2-level factorial design. Every factor column is sign-coded +1/-1 (written +F / -F). An interaction column such as AB or ABC is the column-wise product of its member factor columns, so its sign in each run is the product of the corresponding factor signs. Two columns are aliased (fully confounded) precisely when they are proportional, equivalently when their inner product over the 4 runs has magnitude equal to the number of runs 4 (correlation magnitude 1). List every aliased pair among the main-effect and interaction columns, each as the two column names joined by '-' with the lexicographically smaller name first, all pairs sorted lexicographically and joined by ','; answer 'none' if no pair is aliased.

Factors: A, B, C
Runs:
+A  -B  -C
-A  -B  +C
-A  +B  -C
+A  +B  +C
