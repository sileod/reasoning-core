# Level 0
### Example prompt
Over the prime field of size 13, two univariate polynomials are encoded as coefficient lists (constant term first).
A = [10, 9, 1, 7]
B = [10, 9, 1, 7]
Evaluate both at the shared random point x = 6 and check whether the two polynomials are identical (Schwartz-Zippel identity test).
Answer exactly 'yes' if they are identical, otherwise 'no'.

**Answer:**
yes
