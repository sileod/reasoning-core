## Level 0

### Example 1

**Prompt:**

These are valid codes produced by a single check-digit scheme:
SXIH1, VQRD1, LARB2, 6MQE5, NHK85
The scheme assigns each position a weight cycling 1,2,3,... and combines position-weighted digit values with a modulus that is one of 7, 9, 11, or 13. A small corporate check runs over the code body (all positions except the last), taking the character whose position-weighted digit sum makes the total a multiple of the modulus as the trailing check character.
Given the partial code 4535 with the same scheme, what is its trailing check character?
Answer with exactly one character.

**Answer:**

6
