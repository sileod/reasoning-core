## Level 0

A string is written around a circle, so its circular rotations are considered the same word. Report four values about the word 'bbbbb', separated by commas and in exactly this order: (1) the canonical rotation, defined as the lexicographically smallest of the word's rotations; (2) the 0-based index in the original string 'bbbbb' where that canonical rotation starts, choosing the earliest such index if it occurs at more than one place; (3) the primitive period, the length of the shortest block that, repeated, generates the whole word; (4) the symmetry order, equal to the word length divided by the primitive period. Example: for 'abab' the rotations are abab, baba, abab, baba, so the canonical rotation is 'abab' at index 0, primitive period 2, symmetry order 2, and the answer is abab,0,2,2. The word is: bbbbb

**Answer:** bbbbb,0,1,5
