## Level 0, example 1
### Prompt
On 4 qubits q0..q3, the stabilizer group is generated by the commuting Pauli operators g0..g2, one per line, where each character refers to the qubit in the same column position:
g0 = IIXI
g1 = YIIY
g2 = IZII
Consider the cut given by the bitmask '0010': bit i is '1' when qubit qi is in the cut and '0' when it lies outside it.
Let S_A be the subgroup of the stabilizer group whose elements act as the identity on every qubit OUTSIDE the cut (i.e. supported entirely inside the cut). The order d = |S_A| of this subgroup is a power of two, so the base-two logarithm of d is a non-negative integer.
What is the entanglement entropy, namely the base-two logarithm of d? Report it as a reduced fraction written as "numerator/denominator", for example "1/10" showing that form. Answer with exactly one reduced fraction and nothing else.
### Answer
1/1
