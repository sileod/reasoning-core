# reasoning-core-env

### Overview
- **Environment ID**: `reasoning-core-env`
- **Short description**: Single-turn evaluation over `reasoning_core` procedural tasks with XML formatting.
- **Tags**: reasoning, procedural, single-turn, xml, synthetic

### Datasets
- **Primary dataset(s)**: [`reasoning-core/procedural-pile`](https://huggingface.co/datasets/reasoning-core/procedural-pile), generated by [reasoning_core](https://github.com/sileod/reasoning_core)
- **Source links**: `reasoning_core` library (scorers)
- **Split sizes**: train rows from the pile's `train` split, eval rows from its `test` split; counts via loader args

### Task
- **Type**: single-turn
- **Parser**: the text inside the last `<answer>...</answer>`
- **Rubric overview**: Score computed via the `reasoning_core` task-specific scorer, in [0, 1]

### Quickstart
Run an evaluation with default settings:

```bash
uv run vf-eval reasoning-core-env
```

Configure model and sampling:

```bash
uv run vf-eval reasoning-core-env   -m gpt-4.1-mini   -n 20 -r 3 -t 1024 -T 0.7   -a '{"key": "value"}'  # env-specific args as JSON
```

Notes:
- Use `-a` / `--env-args` to pass environment-specific configuration as a JSON object.

### Environment Arguments

| Arg | Type | Default | Description |
| --- | ---- | ------- | ----------- |
| `num_train_examples` | int | `500` | Rows sampled from the train split |
| `num_eval_examples` | int | `50` | Rows sampled from the test split |
| `seed` | int | `0` | Shuffle seed for both samples |
| `revision` | str | `None` | Pile tag or commit to pin (default: latest) |
| `dataset_name` | str | `reasoning-core/procedural-pile` | Any dataset with `prompt`, `answer`, `task`, `metadata` columns |
| `do_extract_answer` | bool | `true` | Score only the `<answer>` contents |

### Metrics

| Metric | Meaning |
| ------ | ------- |
| `reward` | Task-specific score in [0, 1] |
